# JobFor Deployment Guide

Deploy JobFor to **Vercel** (frontend), **Render** (backend), and **Neon** (database).

---

## Architecture

```
Browser ──► Vercel (React + Vite static) ──► Render (FastAPI) ──► Neon (Postgres)
```

- Frontend calls the backend directly via `VITE_API_BASE_URL` (no proxy).
- Backend creates missing tables at startup (`Base.metadata.create_all`); the Neon
  database already has the schema and data, so no migration step is required.
- Render health check: `GET /health` (no auth).

---

## 1. Database: Neon

Already provisioned. The connection string lives in the repo `.env` as `DATABASE_URL`
(Neon pooler endpoint). You will paste it into Render's dashboard — it is **not**
committed anywhere.

---

## 2. Backend: Render

1. [render.com](https://render.com) → **New +** → **Blueprint**.
2. Connect GitHub, select the `J4v2` repo. Render reads the root `render.yaml`
   (service `jobfor-backend`, `rootDir: backend`, `uvicorn main:app`).
3. Before first deploy, set the env vars marked `sync: false` in the dashboard:

   | Variable | Value |
   |----------|-------|
   | `DATABASE_URL` | Neon connection string from `.env` |
   | `GROQ_API_KEY` | from `.env` (optional, AI features) |
   | `NVIDIA_NIM_API_KEY` | from `.env` (optional, AI features) |

   `SECRET_KEY` is auto-generated by Render. `ALLOWED_ORIGINS` defaults to
   `https://jobfor-frontend.vercel.app` — update it if your Vercel URL differs.
4. **Create Blueprint**. Backend URL: `https://jobfor-backend.onrender.com`.

Verify: `curl https://jobfor-backend.onrender.com/health` → `{"status":"ok",...}`.

---

## 3. Frontend: Vercel

1. [vercel.com](https://vercel.com) → **New Project** → import the `J4v2` repo.
2. Root directory: `frontend`. Framework preset: **Vite** (or rely on
   `frontend/vercel.json`, which pins `@vercel/static-build` + `dist`).
3. Environment variables (build-time):

   | Variable | Value |
   |----------|-------|
   | `VITE_API_MODE` | `real` |
   | `VITE_API_BASE_URL` | `https://jobfor-backend.onrender.com/api/v1` |

   These are already in `frontend/vercel.json`; override in the dashboard only if
   your Render URL differs.
4. **Deploy**. Frontend URL: `https://jobfor-frontend.vercel.app`.

---

## 4. Connect the two

If your Vercel URL is not `jobfor-frontend.vercel.app`, update `ALLOWED_ORIGINS`
in the Render dashboard (Environment → edit) to your real URL.

---

## Notes

- Render **Starter** ($7/mo) keeps the service awake. On the free plan the service
  spins down after 15 min of inactivity and the first request after a spin-down
  takes ~30s to wake.
- `UPLOAD_DIR` is ephemeral on Render — uploaded files are lost on redeploy.
- Both platforms auto-deploy on push to `main`.
